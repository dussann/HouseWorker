# 1. Overview

FixHome follows a layered architecture with a clear separation between presentation, business logic, and data access.

The application is designed as a modular monolith. Each business domain is isolated into its own package, allowing future migration to microservices if required.

The same backend API serves:

* React Native mobile application
* React Admin Panel
* Future third-party integrations

# 5. Backend Layers

Every module follows the same internal structure.

```text
Controller
      │
      ▼
Service
      │
      ▼
Repository
      │
      ▼
PostgreSQL
```

Responsibilities:

**Controller**

* Exposes REST endpoints
* Validates requests
* Maps DTOs

**Service**

* Implements business logic
* Handles transactions
* Coordinates repositories

**Repository**

* Database access
* Spring Data JPA

# 8. Security Architecture

Authentication:

JWT Token

Authorization:

Role-Based Access Control (RBAC)

Roles:

* CUSTOMER
* CRAFTSMAN
* ADMIN

Passwords:

* BCrypt hashing

Every protected endpoint requires a valid JWT.

# 9. Data Flow Example

Customer creates request.

↓

Backend validates request.

↓

Request is stored.

↓

Nearby craftsmen receive notification (future).

↓

Craftsmen submit offers.

↓

Customer accepts one offer.

↓

Job progresses.

↓

Customer leaves review.

# 11. Future Evolution
